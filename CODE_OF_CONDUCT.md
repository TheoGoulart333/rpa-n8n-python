# Code of Conduct

Este projeto deve ser um espaco seguro, respeitoso e construtivo para aprender, contribuir e colaborar.

## Nosso compromisso

Participantes e mantenedores devem tratar todas as pessoas com respeito, independentemente de experiencia, origem, identidade, idioma, localizacao ou nivel tecnico.

## Comportamentos esperados

- usar linguagem acolhedora e objetiva;
- aceitar feedback com boa fe;
- manter discussoes focadas no projeto;
- ajudar iniciantes quando possivel;
- discordar de ideias sem atacar pessoas.

## Comportamentos inaceitaveis

- assedio, insultos ou ataques pessoais;
- exposicao de dados privados;
- comentarios discriminatorios;
- spam ou autopromocao sem relacao com o projeto.

## Aplicacao

Problemas podem ser reportados ao mantenedor pelo e-mail publico informado no perfil do GitHub ou na pagina do projeto.
